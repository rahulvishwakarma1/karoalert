KaroAlert - Smart QR Parking Alert App

KaroAlert makes parking and vehicle communication simple. Attach a QR sticker to your vehicle. When someone scans it, they can instantly alert you, call you, or reach you directly - no more blocked cars, no more waiting.

FOR VEHICLE OWNERS:

- Register your vehicles and generate personalized QR codes

## 8. Data safety

### 8.1 Data collected - ye fields bharo

| Data type | Collected? | Example |
| --------- | ---------- | ------- |
| Name | Yes | User profile name |
| Email address | Yes | Login / account |
| User IDs | Yes | Account ID |
| Phone number | Yes | Login + owner contact |
| Purchase history | Yes | Membership payment records |
| Photos / Videos | No | System photo picker se QR image select hota hai (koi gallery access nahi, app user ke personal photos/videos kabhi nahi padhta) |
| App activity (scans, app interactions) | Yes | Scan history, usage |
| Device or other IDs | Yes | Push notification token |
| Crash logs | Yes (optional) | Stability |

### 8.2 Data sharing

- Data **third parties ke saath shared** nahi hai (except payment gateway Razorpay for payment processing).
- Data **sold** nahi hota.

### 8.3 Security

- Data **encrypted in transit** (HTTPS). Choose: Yes.
- Data **deleted on request** — Choose: Yes (app me Delete Account feature hai).

### 8.4 Data usage

| Type | Purpose | Handled by |
| ---- | ------- | ---------- |
| Name, Email, Phone | Account creation & login | App |
| Phone number | Vehicle owner se contact | App |
| Photos | Only the QR image the user explicitly selects via the system photo picker | App (system picker, no gallery access) |
| Purchase history | Membership records | App / Razorpay |
| App activity | Scan history | App |
| Device IDs | Push notifications | App |

> Note: Location collect nahi hoti, isliye Data Safety me Location mat daalna.
